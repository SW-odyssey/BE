# 최종 v2 검증 기록

2026-11-18, 별도 Docker DB `odyssey_v2_final_local`와 HTTP `127.0.0.1:8084`에서 실행했다. 운영 DB·배포·실제 FE 앱 연결은 하지 않았다.

## 계산과 HTTP 대조

- 2025년 12개월, 매월 681셀 × 7요일 × 4시간대 = 19,068조건. 총 228,816조건을 원본 기반 계산과 대조했다.
- 월별 84개 선택 요청, 총 1,008요청의 매장 순서 불일치 0건. 이 선택 테스트의 표본과 월별 56,000개 오프라인 위치·조건 검증을 구분한다.
- 이유 7,728회 일괄 요청으로 228,816셀·요일·시간대 상태와 코드를 검사했다.
- 프로필 57,204개(681셀 × 7요일 × 12개월)의 상태·상대 막대를 대조했다.
- 잘못된 요청 132건이 예상대로 거부됐다. 빈 결과, 근무 긍정 코드 제외, 원본 추정 인원 미반환도 검사했다.
- V10 적용 및 FE 코드 계약 반영 후 12개월 HTTP 검증을 다시 실행했다. [월별 영수증 요약](http-validation.csv), [총괄 결과](validation-summary.json).

v3 → 최종 v2 재생성 회귀는 datasetId 변경을 제외한 셀 8,172행, 매장 20,304행, 조건 228,816행, 근거 71,723행, 프로필 57,204행에 대해 pandas `assert_frame_equal`을 통과했다. 외부 응답은 기존 문장을 제거하고 코드만 반환하므로 이전 API JSON과 완전히 같은 계약이라는 의미는 아니다. private bundle에는 기존 문장·그래프 메타가 회귀 비교용으로 남지만 새 DB에는 적재하지 않는다.

## DB와 코드

- 공개 배치 12개, 조건 228,816행, 근거 71,723행, 프로필 57,204행, 막대 58,964행이 예상 행 수와 일치했다.
- 잘못된 AVAILABLE 막대 3개, 비표시 프로필에 막대가 있는 경우의 공개를 모두 거부했다. 두 트랜잭션은 롤백했고 감사용 배치 잔여 행은 0이다.
- Java v2 테스트 21개 통과. 대상은 `com.odyssey.recommendation.v2.*`; BE 전체 테스트 실행을 뜻하지 않는다.
- 분석 단위 검증 20개 통과. FE 전달용 테스트 4개와 TypeScript strict 검사 통과.
- V10 이후 최종 로더를 11월 전체 배치로 재실행하고 트랜잭션을 롤백했다. 적재 성공·감사 배치 잔여 0행을 확인했다.
- 기존 v3 DB와 11월·월별 산출물을 덮어쓰지 않았다. 테스트에 사용한 DB는 별도 로컬 볼륨에 보존한다.

## 검증하지 않은 것

정책 75/80/1.25의 만족도 최적성, 공급자의 집계 단위·누락 원인, 매장 실제 고객 구성·예약률·실시간 혼잡도를 검증하지 않았다. 다국어 문구는 전달용 초안이며 언어 검수가 필요하다. Google Maps 및 실제 FE 앱 연결은 후속 개발이다. 비짓서울 사용량 화면과 로컬 로그 불일치는 별도 미해결 항목이며 이번 검증에서 재호출하지 않았다.

## 재실행

아래 명령은 분석 저장소 체크아웃에서 실행한다.

```powershell
python -m scripts.recommendv3.final_v2_acceptance --phase export --root <새-출력-폴더> --baseline-root <기존-v3-월별-bundle-폴더>
python -m scripts.recommendv3.final_v2_acceptance --phase http --root <새-출력-폴더> --baseline-root <기존-v3-월별-bundle-폴더>
python -m scripts.recommendv3.final_v2_schema_audit --help
node --test contracts/recommendation-v2.test.mjs
```

`http`는 이름이 고정된 격리 DB에만 적재한다. 운영 적재 도구가 아니다. 이미 적재된 배치는 `--phase verify`로 HTTP만 검증한다. 실제 원본·공간·매장 파일과 원래 검증 해시가 필요하다. 원본 및 인원 수가 포함된 private bundle은 Git에 올리지 않는다.
